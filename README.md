## Описание программы

Expense Tracker - это графическое приложение для отслеживания личных расходов, разработанное на Python с использованием библиотеки Tkinter. Программа позволяет пользователям удобно записывать, просматривать, фильтровать и анализировать свои расходы.

### Основные возможности:
- Добавление расходов с указанием суммы, категории и даты
- Просмотр всех расходов в удобной таблице
- Фильтрация расходов по категории и периоду дат
- Автоматический подсчет общей суммы расходов
- Сохранение данных в формате JSON
- Загрузка данных при запуске программы
- Валидация вводимых данных

## Требования

- Python 3.6 или выше
- Библиотека tkinter (обычно входит в стандартную установку Python)
